## Stage And Group Behavior

Источник:
- Первый добавленный этап должен сразу быть разблокированным.
- Сейчас не работает смена порядка групп в этапе.
- Можно добавить стрелочки около плюсика для порядка групп.

Критерии:

- Reorder групп внутри этапа должен сохраняться через существующий batch-save, без отдельного параллельного API, если текущая архитектура это поддерживает.
- UI reorder должен быть простым: стрелки вверх/вниз рядом с добавлением/управлением группой.

## Add Catalog Items UX

TaskDB: `#545`.

Источник:
- При добавлении упражнения/рекомендации/теста в программу пациента показывать слева контейнер как на страницах каталогов.
- Использовать такую же панель фильтров по регионам, нагрузке, типу и т.д.
- Нужен мультивыбор: клик выбирает/подсвечивает элемент и добавляет в группу; повторный клик снимает выделение и убирает только из текущей группы.
- Смена фильтра не сбрасывает выбранные элементы.
- Добавление происходит без серверной подгрузки и перезагрузки страницы.
- Каталог загружается один раз при начале редактирования программы и переиспользуется при следующих открытиях.

Связанные существующие элементы:
- `InstanceAddLibraryItemDialog` — текущий механизм добавления.
- Каталоги упражнений/рекомендаций/тестов уже имеют более богатые списки/фильтры.

Критерии:
- Не делать второй "LFK engine"; добавление остается частью treatment program instance editor.
- Не ломать batch-draft/editor-batch semantics.
- Фильтрация должна работать на уже загруженном наборе данных в рамках сессии редактирования.
- Выбор элемента в одной группе не должен удалять такой же элемент из другой группы.

## Individual Instance Items

TaskDB: existing `#193` expanded with this scope.

Источник:
- Врач может создать упражнение/рекомендацию прямо в инстансе программы, не создавая запись в общем каталоге.
- Альтернативно врач может сохранить новый пункт в общий каталог.
- Для индивидуального пункта нужна загрузка видео прямо из программы.
- Видео сохранять в клиентскую папку рядом с видео/фото пациента для оценки техники, но в отдельную папку `indive_program_exercises` (орфография из исходного feedback; перед реализацией лучше подтвердить имя `individual_program_exercises`).
- HLS после загрузки: 480 и 720.
- Нужен режим правки индивидуального пункта в инстансе: название, первичные настройки, перезагрузка видео.
- Если пункт из общего каталога — правка идет в общий каталог; если помечен индивидуальным — правится только внутри инстанса.

Связанные задачи:
- taskdb `#193` уже описывает индивидуальное ЛФК-упражнение с видео. Этот раздел расширяет scope и должен быть прикреплен к `#193`, а не дублироваться отдельным тикетом без необходимости.

Критерии:
- Спроектировать модель индивидуального instance item: где хранится title/settings/media ref, как отличить catalog ref от local override.
- Видео не должно попадать в общий каталог без явного выбора врача.
- Проверить media authorization и HLS pipeline для новых файлов.
- Не писать новое S3/env config; использовать существующие media/upload abstractions.
