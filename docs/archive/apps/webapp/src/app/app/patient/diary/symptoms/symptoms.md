# symptoms

Раздел симптомов на единой странице дневника: `/app/patient/diary` (legacy `/app/patient/diary/symptoms` редиректит сюда через `next.config`).

Пациент видит **назначенные** отслеживания симптомов (в т.ч. созданные врачом или через интегратор/систему). **Новый трекинг из кабинета пациента не создаётся** — UI добавления отключён; `createSymptomTracking` (server action) отвечает **`{ ok: false, reason: "patient_self_create_disabled" }`**; служебные **`general_wellbeing`** (самочувствие с главной) и **`warmup_feeling`** в новом списке **скрыты**.

Блок «Отслеживаемые симптомы» расположен под недельным dashboard. Нажатие на назначенный симптом открывает одну `PatientModal`: форма 0–10 сохраняет только мгновенную запись, а график загружает split-history из существующего `GET /api/patient/diary/symptom-stats`. По умолчанию показан месяц; на мобильном график имеет горизонтальную прокрутку до свежих точек. Журнал сохраняет старые дневные записи в истории, но новая форма их не создаёт. Данные идут через `deps.diaries` (`listSymptomTrackings`, `addSymptomEntry`, …); это только patient surface.
