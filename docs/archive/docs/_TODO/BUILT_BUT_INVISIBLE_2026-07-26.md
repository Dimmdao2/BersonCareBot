По прямому вопросу владельца: «что у нас уже сделано в бэкенде, но не вынесено во фронтенд; может быть
есть такие вещи, которые уже есть, просто не видны».

**Метод.** Сплошная сверка: 521 обработчик `route.ts` против 140 страниц `page.tsx`. Для каждой ручки —
поиск её адреса по всему `apps/webapp/src` и `apps/integrator/src` вне `app/api`. 55 ручек оказались
без единого вызова; 4 из них — ложная тревога (их зовёт service worker вне `src`). Из оставшихся ~51
прочитано и разобрано ~30, начиная с тех, что выглядели как реальная польза. **Остаток не разобран** —
список с числом попаданий по каждой ручке лежит в scratchpad, следующий заход может продолжить с того
же места.

Всё ниже — статический разбор кода. Приложение не запускалось, база не открывалась.

## ⛔ Аналитика платформы — НЕ включать. Моя первая оценка была неверна

Сначала я записал её сюда как «построено и спрятано, дешёвый выигрыш». **Это ошибка, снимаю.**
Расследование (#1019) показало: заглушку поставили **осознанно и правильно**.

За оболочкой `DoctorAnalyticsShell` стоит не сводка, а **сквозной поиск по пациентам**. Каждая плитка с
цифрой на вкладках «Клиенты» и «Приложение» кликабельна и открывает список **реальных людей: имя,
телефон, дата события и прямая ссылка на медицинскую карту**. Выборка `loadDoctorAnalyticsAudience`
**не ограничена клиникой** — то есть глобальный админ получал бы карточки пациентов всех клиник сразу.
Это противоречит и решению владельца 15.07 (аналитика по клиникам, не по людям), и надписи в самой
заглушке «намеренно только агрегаты».

Страницы держат заглушку, но прямой `GET /api/admin/doctor-analytics-metric-accounts` оставался доступен
авторизованному global admin и возвращал patient-level данные без organization scope.

«C6» — настоящий открытый этап (задача **#854**, `IMPLEMENTATION_ROADMAP.md:744`), он ждёт биллинга и
согласованных определений метрик. Текст заглушки **актуален, а не протух**.

**Что нужно ДО включения:** убрать или закрыть пер-пациентский переход с вкладок «Клиенты» и
«Приложение». Вкладки «Контент» и «Сопровождение» — только агрегаты, их можно включать раньше.
Механически написать `page.tsx` — работа на час; вопрос не в ней.

- [x] **#1019-Q1 — закрыть прямой patient-level admin drill-down до C6.** Evidence:
      `apps/webapp/src/app/api/admin/doctor-analytics-metric-accounts/route.ts` возвращает fail-closed
      `409 platform_patient_drilldown_disabled`; route-test
      `keeps patient-level drill-down fail-closed for an authorized platform admin` доказывает, что audience/repository
      не вызываются. C6/UI/aggregate endpoints не включались и не менялись.

**Урок:** «построено, но не подключено» ≠ «забыли подключить». Иногда это карантин. Прежде чем включать
найденное, надо выяснить, почему выключили.
