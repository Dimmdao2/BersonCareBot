# Что осталось от Rubitime после вывода из эксплуатации

Rubitime выведен 27.07.2026. Владелец 19.08 спросил: «надо посмотреть что еще у нас завязано на эту
историю — проверки здоровья рубитайм например?» Ниже — перепись по живому TEST и по репозиторию.

## 1. Живые секреты мёртвой системы в базе — брать первым

В `system_settings` (scope `admin`) лежат **заполненные** значения:

| ключ | состояние |
|---|---|
| `rubitime_api_key` | значение есть |
| `rubitime_webhook_token` | значение есть |
| `booking_url` | ссылка на `dmitryberson.rubitime…` |
| `rubitime_webhook_uri` | пусто |
| `rubitime_schedule_mapping` | пусто |

Поиск по `apps/` и `deploy/` не нашёл **ни одного** читателя этих ключей. То есть это осиротевшие
строки, и две из них — действующие учётные данные к системе, которой мы больше не пользуемся.
На проде значения, судя по всему, настоящие. Ключ и токен, которые никто не читает, но которые
лежат в базе, — это только риск и никакой пользы.

  Rubitime **не показывает** (проверено: в разметке страницы упоминаний нет), то есть поле
