# Проходы владельца по экранам — дословно, с галочками

**Зачем эта папка.** Владелец 27.07: «мой аудит — не оставляй в сообщении. У тебя надеюсь уже есть папочка куда
ты дословно складываешь мои подробные аудиты». **Не было** — до этого его проходы оседали в чате и в разрозненных
файлах, часть пунктов терялась. Теперь единственное место — здесь.

## Правила ведения

1. **Дословно.** Текст владельца сохраняется цитатой, без пересказа и без «улучшения формулировок». Пересказ — это
   уже интерпретация, а именно на ней теряются пункты.
2. **Один проход — один файл**, имя `ГГГГ-ММ-ДД_<роль или экран>.md`. Файлы не переписываются задним числом:
   исправление отмечается галочкой и ссылкой на коммит, а не правкой исходного текста.
3. **Каждый пункт получает маркер** — по конвенции `BACKLOG_CONSOLIDATION_2026-07-26.md` §6.3:
   `[ ]` открыт · `[x]` сделано (со ссылкой-доказательством) · `[-]` отменено/вытеснено владельцем.
4. **Каждый пункт классифицируется**, потому что в одном проходе смешаны три разные вещи:
   - **ДЕФЕКТ** — работает не так, как задумано. Чинится.
   - **ВОПРОС** — «что это значит», «зачем это здесь». Отвечается письменно, ответ ложится в документ по предмету.
   - **РЕШЕНИЕ** — продуктовой механики ещё нет или её форму выбирает владелец. Уходит в план, не в код.
     Смешивать их запрещено: дефект без ответа выглядит как вопрос, а решение, взятое в работу без владельца, —
     это выдуманный скоуп.
5. **Галочка ставится только против реальности** — прогнанного кода или живой проверки, никогда против отчёта
   исполнителя.
