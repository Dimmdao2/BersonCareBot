# Слой прав БД — актуальные документы

Здесь остаются только три действующих источника:

- [`docs/OWNER_DECISIONS.md`](../../OWNER_DECISIONS.md), раздел «Права БД, роли и стены» — решения владельца;
- [`PLAN.md`](PLAN.md) — фактическое состояние и единственный текущий чек-лист;
- [`SCHEME.md`](SCHEME.md) — применённый целевой контракт слоя прав.

Слой declaration/generator, четыре runtime-login, tenant walls, mTLS, retention и живая матрица ролей применены
на named DEV и TEST. Автономной разработки слоя прав на DEV/TEST не осталось. Открытые действия перечислены
только в верхнем чек-листе `PLAN.md`: внешние owner-operated проверки и отдельный будущий PROD cutover.

Датированные брифы, сырые журналы аудитов, промежуточные ревизии и отчёты не являются источниками текущего
состояния и удалены из checkout; при необходимости их история доступна в Git.
