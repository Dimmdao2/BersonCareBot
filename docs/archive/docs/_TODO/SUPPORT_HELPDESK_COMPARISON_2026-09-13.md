# Выбор self-hosted системы поддержки — сравнение (13.09.2026)

Документ сравнения, которого требует критерий завершения исследования в
[`SUPPORT_TICKETS_1070.md`](SUPPORT_TICKETS_1070.md). Запрос владельца 13.09: «найди подходящую для нас
лёгкую простую и стабильную бесплатную систему техподдержки self-hosted».

## Требования, против которых меряем (из #1070)

1. Работает, когда webapp, основное API и основной PostgreSQL лежат.
2. Обращение **без учётной записи** — человек, который не может войти, должен достучаться.
3. Отдельный failure/security-домен: поддержка не читает бэкапы, журналы безопасности, секреты и базу
   основного приложения даже на одном физическом сервере.
4. Первичная обработка и хранение персональных данных — в РФ; нужны экспорт, управляемое удаление,
   понятная политика хранения.
5. Бесплатно, self-hosted, легко, просто, стабильно.

## Кандидаты

| | FreeScout | osTicket | Zammad |
|---|---|---|---|
| Стек | PHP (Laravel) + MySQL | PHP + MySQL | Ruby + PostgreSQL + Elasticsearch + Redis |
| Вес | самый лёгкий, идёт даже на шаред-хостинге | лёгкий, шаред-хостинг | тяжёлый: Elasticsearch 8 обязателен, в сообществе называют ~10 ГБ RAM |
| Цена ядра | бесплатно, AGPL, без лимитов на агентов/тикеты/ящики | бесплатно, GPL | бесплатно, self-hosted |
| Приём без входа | по email из коробки; веб-форма — платный модуль End-User Portal ($12.99 пожизненно на инстанс) | гостевой тикет веб-формой из коробки, проверка статуса по номеру | есть |
| Русский | есть | есть | есть |
| Живость в 2026 | частые релизы (1.8.212, 1.8.213 и далее) | активен: 1.18.4 и 1.17.8, поддержка PHP 8.3/8.4 | активен |

## Безопасность: главный вывод исследования

**Все три в 2026 получили критические дыры ровно в тех путях, которые нам и нужны.** Это не довод против
конкретного продукта — это доказательство, что требование №3 (отдельный домен) не перестраховка.

- **FreeScout:** `CVE-2026-27636` (аутентифицированный RCE), затем `CVE-2026-28289` — обход той заплатки,
  **CVSS 10.0, zero-click: специально составленное письмо в ящик поддержки даёт захват сервера**; и
  `CVE-2026-40498` (CVSS 9.8) — неаутентифицированный доступ к диагностическим и системным инструментам.
  Закрыты в 1.8.212 / 1.8.213.
- **osTicket:** `CVE-2026-22200`, CVSS 8.7, EPSS 73 % — чтение произвольных файлов через экспорт PDF с
  повышением до RCE; **достаточно прав гостя, создающего тикет**, то есть эксплуатируется именно через
  гостевую форму. Закрыт в 1.18.3 / 1.17.7.
- **Zammad:** 11 CVE за 2026, средний балл 6.3 — критических pre-auth RCE в этом ряду нет, но и вес у него
  другой.

Отсюда: настоящая цена любого варианта — **дисциплина обновлений**, а не установка.

## Рекомендация: FreeScout, почтой, агентский интерфейс наружу не смотрит

**Почему FreeScout:**

- самый лёгкий из трёх — PHP и MySQL, отдельная маленькая машина, никакого Elasticsearch;
- ядро бесплатно и без потолков (агенты, тикеты, ящики), лицензия AGPL — «бесплатно» не превращается в
  «бесплатно до третьего оператора»;
- **приём обращений — почтовый ящик**, а это единственный вход, который работает, когда у нас лежит
  вообще всё: человеку не нужен ни наш сайт, ни наша база, ни вход в аккаунт (требования 1 и 2);
- русская локализация, регулярные релизы.

**Почему не osTicket:** его козырь — гостевая веб-форма из коробки — это и есть постоянно открытая
публичная веб-поверхность, через которую и прошёл `CVE-2026-22200`. У FreeScout при почтовом приёме
публично не выставлено ничего: агентский интерфейс закрывается VPN или списком адресов, наружу торчит
только забор почты. Это меньшая поверхность, несмотря на то, что худшая дыра FreeScout тоже пришла письмом.

**Почему не Zammad:** он не «лёгкий и простой». Elasticsearch, Redis и память под них — это отдельная
эксплуатация, а обслуживать её некому.

**Нулевой вариант для честности:** общий почтовый ящик без хелпдеска вообще. Легче и безопаснее всего, но
нет ни номера обращения, ни истории, ни разделения между операторами — то есть ровно то, чего сейчас и не
хватает. Брать его есть смысл только если обращений единицы в неделю.

## Что нужно сделать при внедрении (не входит в это исследование)

- [ ] Отдельная машина или изолированный контейнер: без доступа к бэкапам, журналам безопасности,
      секретам и БД приложения. Размещение в РФ.
- [ ] Агентский интерфейс не публичный: VPN либо список разрешённых адресов.
- [ ] Автообновления и подписка на advisories — исходя из того, что 2026-й показал.
- [ ] Политика хранения: срок, экспорт, удаление по требованию.
- [ ] Веб-форма — только если почты окажется мало; тогда модуль End-User Portal, $12.99 пожизненно.
