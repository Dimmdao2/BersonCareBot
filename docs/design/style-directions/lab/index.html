Theme Scaffold

theme-e.css — entry point (imports partials in cascade order)

  • e-tokens.css — CSS custom properties: palette, spacing, radii, shadows
  • e-lists.css — patient roster rows, appointment list items
  • e-calendar.css — schedule grid, day-picker, slot chips
  • e-tables-forms.css — data tables, inputs, selects
  • e-catalog-media.css — exercise / content catalog cards, media thumbnails
How to use: Open any snapshot in a browser (served from 127.0.0.1:5317). Edit the e-*.css files to apply theme overrides — changes reload live if your editor or browser auto-refreshes. All snapshots share the same theme-e.css layer injected as the last stylesheet, so it wins specificity over the inlined Next.js CSS.
