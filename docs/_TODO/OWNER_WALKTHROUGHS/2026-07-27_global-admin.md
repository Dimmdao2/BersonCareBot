## 9. Журнал операций

- [x] **🔴 ДЕФЕКТ — ПОЧИНЕНО** `e56dcc18f`: «не работает (см скриншот)» — «Не удалось загрузить журнал
      (http_500)», панель «Ошибки регистрации» показывает только «network».
      **Корень не угадан, а доказан противоречием контрактов:** запрос журнала делал
      `LEFT JOIN platform_users`, а стена платформенной роли ЯВНО ассертит отсутствие у неё `SELECT` на
      `platform_users` — то есть запрос обязан был падать всегда. Платформенный путь больше не джойнит
      identity (имя актора отдаётся пустым), клиниковый джойн сохранён. Панель регистрации — соседний
      случай того же класса: её ручка не проставляла принципала вовсе.
      Мигр. `0261` даёт платформе читать ровно три типа событий воронки через булев предикат
      (SECURITY DEFINER, возвращает только `true/false`, идентификаторов не отдаёт).
      **Гейт деплоя обновлён вместе с миграцией** (105→106 secdef) — иначе выкатка упала бы посреди закрытия.
      **Живьём на TEST ещё не проверено.**
