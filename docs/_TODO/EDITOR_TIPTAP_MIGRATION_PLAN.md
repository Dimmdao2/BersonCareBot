# Единый редактор платформы: Tiptap Simple Editor

> Решение владельца 16.09.2026 заменяет прежний вариант с markdown-roundtrip: все форматированные редакторы
> платформы работают через один `TiptapEditor`; старый ограниченный движок удаляется; канонический формат новых
> изменений — versioned Tiptap JSON. История прежнего решения остаётся в Git.

## Контракт

- Один UI-примитив: `apps/webapp/src/shared/ui/doctor/TiptapEditor.tsx`.
- UI и поведение основаны на актуальном бесплатном шаблоне Tiptap Simple Editor, исходники компонентов лежат рядом
  в `shared/ui/doctor/tiptap/**` и используют токены платформы.
- Значение хранится как `tiptap-json:v1:<JSONContent>`. Markdown не является форматом хранения и не импортируется.
  Оставшиеся старые строки открываются как буквальный plain text и при сохранении становятся Tiptap JSON.
- Reader-пути отображают Tiptap JSON. Превью, рассылки и внешние каналы получают
  отрендеренное дерево, безопасный HTML поддерживаемого подмножества либо plain text — не сырой JSON.
- Лимиты относятся к видимому тексту. Отдельный защитный лимит сериализованного документа не меняет продуктовый
  лимит символов.
- Медиа вставляется узлами image/link через существующую медиатеку. URL проходят прежние зональные и публичные
  проверки доступа.

## Поверхности

- CMS/контент.
- Рекомендации, включая свободную рекомендацию внутри лечебной программы.
- Рассылки.
- Цели и задачи шаблонов и назначенных лечебных программ.
- Полные описания организации и специалистов на публичной странице.
- Форматированные коммерческие шаблоны.

Простые input/textarea, заметки без форматирования и типизированные шаблоны системных уведомлений не являются
rich-text редакторами и остаются обычными полями.

## Совместимость и удаление старого кода

- Удалены старый `MarkdownEditor`, его ограниченный набор расширений и генератор markdown-сниппетов медиа.
- Удалены Markdown-importer, Markdown-renderer и их зависимости; активного Markdown-пути в платформе нет.
- Все write-поверхности импортируют только `TiptapEditor`; второго активного редактора в коде быть не должно.

## Приёмка

- Статические проверки выполняются только для затронутых файлов и связанных серверных преобразований.
- Живую UI-приёмку проводит владелец отдельно; в рамках этой замены агент её не запускает.
