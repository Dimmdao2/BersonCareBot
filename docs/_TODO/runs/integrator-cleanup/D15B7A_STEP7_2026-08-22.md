## Изменение

Добавлена timestamp-forward migration
`apps/webapp/db/drizzle-migrations/20260822T200000_remove_legacy_identity_resolver_signatures.sql`.
Она под owner-маркером `app_seam_identity_lookup_owner` удаляет ровно три временных делегата:

1. `app.pre_session_resolve_identity(uuid)`;
2. `app_ext.resolve_variant_a_identity(uuid)`;
3. `app_ext.resolve_variant_a_physical(uuid)`.

Миграция не содержит `GRANT`, `REVOKE`, policy или role DDL. В `contract.sql` и
`declaration.ts` удалены те же три определения/записи; generated privilege artifacts пересобраны.
Двухпараметрические `(uuid,text)` варианты остаются единственным проходом.

## Перепись вызовов до снятия

Исполнены:

```bash
node /home/dev/brain/tools/code-search.mjs "pre_session_resolve_identity" --repo bcb -k 100
node /home/dev/brain/tools/code-search.mjs "resolve_variant_a_identity" --repo bcb -k 100

sudo -n -u postgres psql -X -h /var/run/postgresql -d bcb_webapp_dev -v ON_ERROR_STOP=1 -At -c "BEGIN READ ONLY; SELECT p.oid::regprocedure FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace WHERE n.nspname IN ('app','app_ext') AND p.proname IN ('pre_session_resolve_identity','resolve_variant_a_identity','resolve_variant_a_physical') ORDER BY 1; ROLLBACK;"
```

DEV catalog before candidate application contained all six overloads. `pg_proc.prosrc` inspection
found no one-argument call in an installed function body: `current_actor_user_id`,
`current_patient_user_id`, `assert_port_context_claim` and the two-argument root use the kind-aware
variants. Application runtime calls only
`SELECT app.pre_session_resolve_identity($1::uuid, $2::text)`; active migrations contain only the
two-argument `regprocedure` reference. The remaining source matches were the three compatibility
definitions/declaration records, their intended `DROP FUNCTION`s, and DB-proof tests. Proof tests
that actually resolved a reference now name `'actor'` explicitly.
