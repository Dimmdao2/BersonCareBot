# DEV отстаёт по схеме от TEST — агенты проверяют работу не на той базе

Rules: `AGENTS.md` — Маршрут, CORE rules, §1 «Миграции», §6, §24. Language: internal work is English.

⚠️ Один ход, следующего не будет; всё на переднем плане; коммит до конца хода (если правки будут).

Authority: находка хода выкатки на TEST 04.08. `ORCH_OPS`.

Источник оракула — отчёт выкатки, дословно: «Сравнение с DEV сделать буквально не удалось — таблицы там нет
вообще… то есть просто не мигрирована на эту фичу, `migrate-dev.sh` не прогонялся».

## Почему это важнее, чем звучит

Все проверки «живьём» в этой работе делаются на DEV. Если DEV отстаёт по схеме, то «проверено вживую» означает
проверено на другой базе, чем та, куда поедет код. Сегодня это уже стоило нам двух кругов: аудит поднимал воркер
на состоянии, которое не воспроизводилось командой, а грантовые разрывы вскрывались по одному.

## Работа

1. **Измерь расхождение, а не устраняй вслепую:** какие миграции применены на TEST и не применены на DEV, и
   наоборот. Числа и список тегов — в отчёт.
2. **Прогони штатный путь миграции DEV** до состояния ветки `feat/doctor-ui-rebuild`. Если штатного пути не
   существует или он падает — это и есть находка, назови её прямо, не обходи руками.
3. **Проверь, что после синхронизации DEV пригоден для работы:** приложение поднимается, воркер доставки
   стартует, вход по почте проходит. Если что-то ломается именно из-за догнанных миграций — это ценнее самой
   синхронизации, опиши подробно.
4. **Не чини найденные дефекты кода** в этом ходе, если это не однострочная опечатка: собери список.
5. **Скажи, почему DEV отстал** и что мешает ему отставать снова — это вопрос про механику, а не про
   сегодняшний прогон.

## Границы

- **PROD не трогать.** TEST не трогать — он только что выкачен и здоров.
- Данные DEV не пересоздавать и не сбрасывать: задача — догнать схему, а не завести чистую базу.

## Готово значит

- Расхождение измерено и названо списком.
- DEV на схеме ветки; приложение, воркер и вход по почте проверены после синхронизации.
- Названа причина отставания и что его повторит.
