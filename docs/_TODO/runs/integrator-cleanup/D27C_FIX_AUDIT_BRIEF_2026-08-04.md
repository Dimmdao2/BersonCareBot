1. **Пройди цепочку сам** под `DB_PRINCIPAL_CONTEXT_MODE=locked`: запрос → строка в очереди → воркер забрал →

2. **Узкий ли аксессор на самом деле.** Главный риск замены гранта на SECURITY DEFINER — что через него можно
