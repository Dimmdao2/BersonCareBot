«починить» их через `git checkout` в этом клоне нельзя; это артефакт среды клона, а не содержимого
репозитория.

Ни один `*.ts` — ни продуктовый, ни тестовый — не остался изменённым. Каждая из 26 поломок
откатывалась через `git checkout -- <файл>` с немедленной проверкой `git status --porcelain`;
драйвер прогона отказывался работать, если файл был грязным до правки. Созданный мной файл — только
этот отчёт.

## Вне области

Замечания, которые работой не становятся и в вердикт не входят — записаны, чтобы не потерялись:

- `dedup.ts` не ограничивает длину ключа; очень длинный fingerprint от провайдера даст очень длинный
  ключ. Карта такого требования не содержит.
- `deliveryTargetsPort.ts:34` берёт `Date.now()` напрямую для подписи запроса — тестируемость
  времени в этом порту нулевая. Уровень 2 такого требования не ставит.
- `notificationDeliveryAttempts.ts` пишет по одной строке на канал в цикле без батча. Вопрос
  производительности, не потери.
