# VK-кнопки на TEST нет: проекция «провайдер настроен» не пересчитывается

Rules: `AGENTS.md` — Маршрут, CORE rules, §1 «Миграции», §5, §6, §9, §24. Language: internal work is English.

⚠️ Один ход, следующего не будет; всё на переднем плане; коммит до конца хода.

Authority: владелец 04.08 — «vk id довести до рабочего», ключи он завёл сам. Живая проверка на TEST после
деплоя 04.08. `ORCH_OPS`.

Источник оракула — отчёт прогона деплоя, дословно: «производная проекция `oauth_vk_enabled` (та, что решает
«настроен ли провайдер») застряла на `false` с момента миграции 0352, и не пересчитывается… установленное на
TEST тело `public.sync_registered_app_runtime_setting()` не содержит VK-ветку вообще».

## Что это значит

Владелец сделал свою часть: завёл `vk_id_application_id`, `vk_id_client_secret`, `vk_id_redirect_uri` и включил
тумблер. Система же считает провайдера ненастроенным, кнопки на экране входа нет, а `POST /api/auth/oauth/start`
с `provider: "vk"` отвечает `501 oauth_disabled`. То есть с точки зрения владельца VK просто не работает.

Отдельно тревожный факт: часть миграции `0352` применилась, а её правка функции — нет. Это не только про VK.

## Работа

1. **Разберись, почему тело функции на TEST старое,** прежде чем чинить. Миграция применилась не полностью —
   это либо `CREATE OR REPLACE`, перекрытый более поздним оверлеем деплоя (тот же класс, что уже ловили с
   владельцами SECURITY DEFINER функций), либо ветвление внутри самой миграции. Назови настоящую причину.
2. **Почини так, чтобы это не вернулось при следующем деплое.** Если виноват оверлей — правится оверлей, а не
   только функция; иначе следующая выкатка снова затрёт. Прежний случай ровно этого класса описан в очереди
   аудита (`eaafe46d9`) — прочитай и не повторяй ошибку.
3. **Пересчитай проекцию для уже заведённых значений** — недостаточно починить функцию на будущее, надо чтобы
   VK заработал сейчас. Миграция: временный номер в клоне, окончательный присвоит лид.
4. **Проверь остальные провайдеры тем же вопросом:** у Яндекса/Google/Apple проекция считается верно на TEST?
   Если где-то то же расхождение — это часть той же поломки, а не новый скоуп.
5. **Докажи на TEST после применения:** проекция `true`, кнопка на экране входа есть, `start` отдаёт редирект,
   а не `501`. Дальше клика идти не надо — вход завершает владелец.
