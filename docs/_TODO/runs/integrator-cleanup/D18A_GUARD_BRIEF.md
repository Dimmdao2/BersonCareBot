## Что нужно

Проверка, которая знает нынешний список файлов с сырыми вызовами (`.query(`/`.query<` с текстом SQL) в
`apps/integrator/src` и `apps/webapp/src`, и **падает, если появится файл вне этого списка**.

- Список замороженного долга хранится рядом с проверкой в явном виде, отсортированный, с комментарием «долг, чистится
  по плану D18c — не добавлять».
- Разрешено и в список не попадает: файлы миграций и деплойные SQL, загрузчик миграций, низкоуровневый клиент пула,
  вызовы через параметризованную обёртку drizzle (`sql` tagged template, `.execute()`).
- Проверка встроена туда, где её реально увидят: в существующий линт/скрипты проверок пакета, а не отдельной командой,
  про которую забудут. Найди, как подключены соседние проверки, и подключи так же.
- Уменьшать список можно свободно (файл почистили — строка ушла), увеличивать — нельзя.

## Приёмка

- Проверка проходит на текущем дереве.
- Добавь временно сырой вызов в любой файл вне списка — проверка падает с внятным сообщением, где именно и что делать;
  убери — снова зелено. Отчёт должен содержать точный текст падения.
- Удаление строки из списка при живом сыром вызове в этом файле — тоже падение (иначе список можно «почистить» враньём).
- `pnpm --filter webapp lint` и проверки интегратора зелёные.

## Ограничения

- Существующий сырой SQL не чинить: это D18b/D18c, отдельные работы.
- Не трогать семь файлов `directPublic` сверх включения их в список — их переписывает владелец отдельно.
- Никаких `git add -A`. Коммит в этом клоне, без push и merge.

## Отчёт

`где лежит проверка и список → как подключена → точный текст падения на подсаженном вызове → размер списка по каждому
приложению`.
