## Что закрыть (порядок — по цене ошибки)

- **N1.** Ключ дедупликации собирается не из того набора полей: выбросить `source` (или `type`) из
  канонического ключа — весь набор зелёный, а два разных события схлопываются в одно. Тест обязан
  фиксировать СОСТАВ ключа, а не только его устойчивость к порядку.
- **N2.** Ветка с принципалом арендатора в журнале пропусков не исполняется ни разу: все три теста подают
  пустую организацию. Добавить случай с организацией.
- **N3.** Соответствие «колонка → значение» во вставке не проверяется: перестановка `status` и `reason` в
  списке колонок оставляет набор зелёным, а в журнал уходит `status='muted'`. Тест обязан ловить пару.
- **N4.** Счётчик попыток может перестать расти — никто не ловит: строка, которая падает всегда, будет
  повторяться **вечно**, потому что до предела попыток она не дойдёт.
- **N5.** Причина смерти строки не проверяется: затёртая ошибка оставляет набор зелёным, а оператор видит
  пустое поле вместо причины.
- **N6.** F7 закрыл половину: строка из одних пробелов ловится, пробелы **по краям** — нет.
- **N7.** Ограничение частоты в шлюзе не покрыто ни одним тестом, хотя договор модуля прямо называет его
  одной из трёх своих обязанностей.
- **N8.** Наружу может уйти не тот ключ дедупликации, что занимался в порту (он попадает в журналы вебхуков
  обоих мессенджеров).
- **N9.** Обрыв цепочки намерений на «дырке» не покрыт (аудитор сам оценил влияние как низкое — закрывать
  последним, если останется время).

**N10 — не тест, а неверное обоснование:** в комментарии теста и в аудите написано «единственный продовый
вызов», а вызовов больше одного. Исправить формулировку в комментарии, ничего не переписывая.
**N11 — долг, а не находка:** заглушка маршрутизирует по тексту запроса и даёт ложное красное. Если
закрывается малой правкой заглушки — закрыть; если нет — строка в отчёт, работой не заводить.

## Как доказывать (гейт приёмки)

По каждой находке: внести **ровно ту** поломку, что названа в аудите, прогнать **полный** набор
интегратора (не узкий файл — иначе не видно, что краснеет именно нужный тест), показать красное,
откатить, показать зелёное. В отчёте — файл, строка, вывод.
