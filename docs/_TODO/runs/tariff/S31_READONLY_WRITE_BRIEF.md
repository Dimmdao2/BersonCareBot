## Задача

Каждый тест: состояние «только чтение» → попытка записи → видимый отказ, порт данных не вызван.

**Обязательное доказательство:** убрать из стража ветку отказа записи в режиме «только чтение» — каждый новый тест
обязан покраснеть. Приложить дословный вывод до и после, потом вернуть код на место.
