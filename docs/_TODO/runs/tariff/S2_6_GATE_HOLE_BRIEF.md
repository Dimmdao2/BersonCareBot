## Что не так — доказано лидом внесением поломки

Гейт `src/modules/org-entitlements/ladderConstants.ts` (коммит `6b64ba7d8`) ловит только литерал,
стоящий ПРЯМО в свойстве, и `??`/`||` с литералом справа. Достаточно дать константе ИМЯ, и гейт молчит.
Дословная проверка лида: в `service.ts` добавлено

```ts
const GRACE_DAYS = 14;
const TERMINAL = 'disabled';
export const agentPolicy = { graceDays: GRACE_DAYS, terminalState: TERMINAL };
```

`npx vitest run src/modules/org-entitlements/ladderConstants.test.ts` → **7 passed, 0 failed**. То есть
агентская длительность и агентское конечное состояние прошли гейт целиком. Это ровно тот класс, ради
которого пункт 2.6 существует; сам гейт при этом хороший (дерево разбора, а не регулярка) — его надо
дотянуть, а не переписывать.

## Что сделать

1. **Резолвить идентификатор до его значения внутри файла.** Свойство `graceDays: GRACE_DAYS`, где
   `GRACE_DAYS` объявлена в этом же файле как `const` с литералом, — это нарушение вида `literal`, с
   указанием строки САМОГО свойства и упоминанием имени константы в тексте нарушения. То же для
   `?? GRACE_DAYS` (вид `fallback`). Цепочку `const A = 14; const B = A;` тоже разворачивать.
2. **Объявление, само по себе не использованное в поле владельца, нарушением НЕ считать.** Файлы полны
   безобидных чисел; ловим значение, доехавшее до поля владельца, а не любое число в файле. Иначе гейт
   станет шумным, его отключат, и он перестанет ловить что-либо.
3. **Самотесты гейта дополнить именно этой поломкой** — по одному на каждую форму: именованная
   длительность, именованное конечное состояние, именованная подстановка, двухзвенная цепочка. Каждый
   самотест обязан краснеть, если убрать соответствующую ветку резолва.
4. Импортированные из других модулей константы: если резолв через границу файла не делаешь — так и
   написать в комментарии гейта одной строкой (известная граница), не выдавая за полное покрытие.

## Приёмка

- поломка лида выше (`GRACE_DAYS` + `TERMINAL` + `agentPolicy` в `service.ts`) даёт КРАСНЫЙ гейт с точным
  `file:line` по каждому из двух полей — привести дословный вывод до и после;
- прогон `src/modules/org-entitlements/` целиком зелёный, число тестов до и после названо;
- каждый новый самотест краснеет при снятии своей ветки — дословный вывод;
- `pnpm --filter webapp lint` и `typecheck` зелёные;
- галочки плана не ставить, push и merge не делать.
