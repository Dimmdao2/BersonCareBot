## Замер ведущего — это факт, не гипотеза

Кликовый прогон по живому TEST 22.08 под врачом `dimmdao@yandex.ru`: на главной врача кнопка
**«Выполнить»** у задачи даёт **500**:

```
POST /api/doctor/tasks/<id>/complete → 500
```

в журнале webapp в ту же секунду:

```
[cause]: error: permission denied for table outgoing_delivery_queue
code: '42501', routine: 'aclcheck_error'
```

То есть завершение задачи ставит запись в `public.outgoing_delivery_queue` под принципалом персонала, а
прав на эту таблицу у роли персонала нет и по замыслу быть не должно: очередь — поверхность доставки.

## Задача

1. **Найди путь целиком** — от маршрута `POST /api/doctor/tasks/<id>/complete` до оператора, который пишет
   в очередь. Назови `path:line` каждого звена.
2. **Определи, как эта постановка должна выглядеть по канону.** В репозитории уже есть правило и уже есть
   двери: фильтр стоит на ПОСТАНОВКЕ в очередь, а разбор очереди идёт под инфраструктурной ролью.
   Найди, как ставят в очередь СОСЕДНИЕ живые маршруты вебаппа (их несколько), и сделай так же —
   ⛔ **не заводя второго пути к той же записи** (§5). Если подходящая дверь уже есть — используй её,
   новый корень заводится только если ни одна существующая не делает нужного.
3. **Почини.** Права — только через `declaration.ts` + генератор. ⛔ Миграции прав не выдают: ни
   GRANT/REVOKE, ни CREATE/ALTER ROLE, ни ALTER DEFAULT PRIVILEGES, ни CREATE POLICY. Если нужен новый
   корень — миграция `CREATE OR REPLACE` с гейтом `require_accepted_context` первым исполняемым оператором,
   тело берётся побайтно из `pg_proc` именованной DEV, таймштамп строго больше последней применённой
   (мигратор идёт по watermark `created_at`, НЕ по хешу).
4. **Разбор прав по §1** пишется в отчёт: какие отношения трогает тело, под какой ролью исполняется,
   хватает ли ОБЪЯВЛЕННЫХ прав, чтобы тело ВЫПОЛНИЛОСЬ. Помни про класс «право требует ТРИГГЕР» — для него
   есть явный маркер `FunctionRelationSurface.requiredByTrigger`, обходить гейт нельзя.
5. **Проверь тот же класс рядом.** Завершение задачи — вряд ли единственный экран персонала, который
   ставит в очередь. Перечисли все такие места и скажи, какие из них сегодня упали бы так же. Чини только
   те, что на пути живых экранов врача; остальное — строка в отчёте и вопрос (§24.6).
