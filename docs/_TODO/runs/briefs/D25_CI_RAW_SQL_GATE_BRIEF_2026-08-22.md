## Что красное (замер ведущего)

`pnpm run ci` на голове `31c01bb86` падает на первом же шаге `lint`:

```
check-no-new-raw-sql: raw SQL boundary violation.
Raw .query(...) or dynamic-member query bypass outside named DB boundaries:
  - apps/integrator/src/infra/db/writePort.identityRootReachability.audit.test.ts:98
Use the owning application's Drizzle port/parameterized sql`...`.execute() path;
do not add an allowlist entry.
```

Нарушение — вот эта конструкция (строки ~96–101), динамический member-доступ к `.query` через каст:

```ts
const db: DbPort = {
  async query<T>(text: string, params?: unknown[]): Promise<DbQueryResult<T>> {
    return (await (provider as unknown as { query: (t: string, p?: unknown[]) => unknown }).query(
      text, params,
    )) as DbQueryResult<T>;
  },
  ...
```
