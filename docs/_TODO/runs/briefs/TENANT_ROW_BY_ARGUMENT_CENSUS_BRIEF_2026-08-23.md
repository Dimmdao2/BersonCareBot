# Перепись класса: стенованная строка выбирается по аргументу, а не по принятому контексту

Три круга аудита подряд на одной ветке нашли три разных корня одного класса. Значит это не баг, а
класс, и его надо не чинить по одному, а **пересчитать целиком**.

**Источник оракула:** `docs/_TODO/UI_FINISH_AND_REAUDIT_2026-07-22/WORK_ORDER.md` — «узкая роль интегратора не мешает доставке»

Канон — `AGENTS.md` (`grep -n "^## \|^### " AGENTS.md`), §1, §5, §10a.

## Класс

Тело `SECURITY DEFINER`-корня выбирает строку арендного отношения по **аргументу вызывающего**
(`WHERE organization_id = p_organization_id`) вместо **принятого контекста**
(`WHERE organization_id = app.current_org_id()` плюс явная сверка аргумента с контекстом и `42501`
при несовпадении). Гейт при этом на месте и выглядит правильно — поэтому глазами не видно.

Три уже найденных примера (не чинить их заново, они разобраны):

- `app.read_integrator_clinic_delivery_credential(text,uuid)` — закрыт круг 3;
- `app.read_integrator_google_calendar_setting(text,uuid)` — закрыт круг 4, живьём читал
  `google_refresh_token` чужой клиники;
- `app.saas_billing_effective_tariff(uuid,uuid)` — найден, НЕ закрыт; живой утечки сегодня нет,
  потому что `EXECUTE` на него узкой роли не выдан.

## Что сделать

1. **Главный результат — таблица, а не правки.** Пройди ВСЕ `SECURITY DEFINER`-корни в `app`/`app_ext`,
   которые читают или пишут отношения с арендной стеной, и по каждому ответь одной строкой: откуда
   берётся организация — из контекста, из аргумента со сверкой, или из аргумента без сверки. Метод
   переписи назови явно, чтобы я его повторил.
2. Для каждого найденного «из аргумента без сверки» отдельно скажи, **достижим ли он сегодня**: есть ли
   у какой-нибудь рантайм-роли `EXECUTE`. Латентное и живое — разные вещи, и владельцу нужно видеть,
   что из этого горит.
3. Чинить в этом проходе — только те, что **достижимы сегодня**. Латентные оставь в таблице; их
   очередь определит ведущий. Не превращай перепись в бесконечную стройку.
4. Права и гейты — только через `declaration.ts` + генерация (`--all`, `--all --port-context-only`,
   `--all --check` побайтово). В миграции нет `GRANT`/`REVOKE`/`CREATE POLICY`.

  возвращающая выборку по аргументу.
- `typecheck`, `lint`, `definer-tenant-predicate.test.mjs` — зелёные.
