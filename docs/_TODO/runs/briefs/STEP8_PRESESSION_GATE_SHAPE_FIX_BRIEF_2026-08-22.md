## Что сломано (замер ведущего, живой отказ)

`bash deploy/host/migrate-dev.sh --execute` на DEV падает на reconcile:

```
ERROR:  pre-session exact gate missing or mismatched: app.record_collapsing_audit_event(text,uuid,uuid,text,text,text)
```

Причина найдена и однозначна. Проверяющий блок (`generate.mjs`, функция `preSessionGateVerifierLines`)
среди прочего краснеет, если в тексте тела ДО `PERFORM app.require_accepted_context` встречается `:=`
или ` DEFAULT `. В теле, приземлённом шагом Ш8
(`20260822T180000_one_door_records_the_act_of_binding_a_person_to_medicine.sql`), блок `DECLARE` содержит
инициализаторы: `v_inserted_first boolean := false`, `v_volume bigint := 0`, `v_alarm boolean := false`,
`v_uuid_re constant text := '…'`, `v_crossing_actions constant text[] := ARRAY[…]`.

**Гейт прав по существу, а не придирается:** инициализаторы `DECLARE` выполняются при входе в блок,
то есть ДО первого оператора — до приёма контекста. Требование «ничего не исполняется до двери» нарушено
буквально. Поэтому чинится ТЕЛО, а не гейт.
