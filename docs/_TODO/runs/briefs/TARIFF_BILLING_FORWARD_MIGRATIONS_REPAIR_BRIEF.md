# Тарифы и биллинг — восстановление пропущенных DEV-миграций

## Разрыв в пути человека

Высокий номер в журнале DEV скрывает четыре пропущенных изменения тарифов и биллинга и два изменения очистки
старого бронирования. Поэтому регистрацию клиники, frozen-тариф оплаченного периода, чтение платёжного провайдера
и отсутствие старых каталогов нельзя считать реально применёнными на DEV.

## Authority и границы

- `AGENTS.md` §1, §4a, §9–10, §24.
- `docs/_TODO/NIGHT_WAVE_AUDIT_QUEUE_2026-07-28.md`: номера `0324`–`0327` уже забронированы.
- Исходные принятые миграции: `0291`, `0298`, `0304`, `0305`, `0318`.
- PROD и TEST не трогать. Старые файлы и существующие строки Drizzle ledger не менять.
- Не проектировать новое поведение: только forward-only повтор уже принятого SQL.

Источник оракула: этот bounded brief, раздел «Authority и границы» — «только forward-only повтор уже принятого SQL».

## Реализация

1. `0324` повторяет итоговое действие `0291` и остаётся идемпотентной.
2. `0325` объединяет идемпотентный cleanup `0298` и `0304`: старые product-каталоги и пять legacy booking
   projections отсутствуют; канонические `be_*` таблицы не затрагиваются.
3. `0326` повторяет итоговый SQL `0305` без смысловых изменений функций тарифного доступа.
4. `0327` повторяет `0318`: fixed-key capability `app.read_saas_billing_payment_provider()`, без общего
   `SELECT` на `system_settings`.
5. В feature-клоне journal `idx/when` временные. Окончательную следующую последовательность назначает лид при
   land после синхронизации с фактическим `feat` и миграцией Track D `0323`.

## Проверка этапа

- Сравнить каждый forward SQL с исходным по исполняемым statements, игнорируя только комментарии и номер.
- Запустить journal/freeze/diff gates и существующие точечные тарифные/биллинговые проверки, которые покрывают
  `0291`, `0305`, `0318`; для cleanup доказать отсутствие старых таблиц и сохранность канонических таблиц.
- Не применять DEV до независимой приёмки. После PASS лид синхронизирует journal, land и выполняет один
  `bash deploy/host/migrate-dev.sh --preflight && bash deploy/host/migrate-dev.sh --execute`.
- Документация получает фактическое состояние и доказательство в том же land-коммите; прежние ложные утверждения
  «применено на DEV» исправляются, а не дублируются новой строкой.
