## Задача

Владелец 22.08: живая проверка на TEST **не блокирует работу**, она блокирует только закрытие этапа в
документах. Поэтому здесь делается вся code-side часть, а живые гейты остаются открытыми в плане.

1. **Перепись перед снятием.** По каждому кандидату на снятие (sweep-джоба специалиста, её route, запись в
   registry, host-cron строка) докажи `path:line`, что его функцию уже выполняет резидентный процесс
   (Ш9 закрыт 21.08: один резидентный процесс, один замок, один цикл) и write-time producer. Кандидат без
   такого доказательства НЕ снимается.
2. **Снятие.** Удали только доказанные дубликаты. Legacy reconciliation-sweep специалиста снимается только
   если сверка (1) из плана D30 уже выполнена и её результат зафиксирован; проверь это по документам, не
   по памяти. Если сверка не выполнена — оставь sweep и напиши почему.
3. **Host cron** трогается ТОЛЬКО через `node /home/dev/brain/tools/cronport.mjs`. `crontab -l | … | crontab -`
   и `crontab <файл>` запрещены абсолютно. Сначала `cronport list`; снимай только реально найденную устаревшую
   строку. Если строк нет — это no-op, так и запиши.
4. **Проверка поведения.** По каждому снятию — целевой тест или существующий, доказывающий, что доставка
   по-прежнему происходит через резидентный путь. Тест на отсутствие файла/строки исходника писать запрещено.
