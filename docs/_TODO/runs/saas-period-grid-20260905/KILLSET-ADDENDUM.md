продление», и вступает в силу только на границе `currentPeriodEndsAt`.

## P. Одна исполняемая декларация доступа (Т14 п.6, закрытие F-1/F-2/F-7)

Оракул владельца, дословно: «доступ к БД остаётся одной исполняемой декларацией
(`deploy/postgres/privileges/declaration.ts`) — сгенерированный SQL только вывод». Brief: определить,
является ли она **единственной рукописной исполняемой авторитетностью**; рукописная копия решений о
доступе в соседнем файле, способная разойтись, — реальный FAIL. Все пункты — **ВЗГЛЯД**: разовое
свойство архитектуры и состояние каталога, доказывается чтением механики генератора, runtime-импортом и
rollback-only интроспекцией. Постоянные тесты по тексту исходника/SQL запрещены (brief, §10a).

| ID | Поломка |
|----|---------|
| P1 | Авторитетность расщеплена: `relation-access.ts` / `function-census.ts` / `drizzle-insert-surface.ts` (или иной импортируемый файл) содержит **самостоятельно поддерживаемое рукой** решение о доступе, которое может разойтись с `declaration.ts` и воспроизвести класс `42501`. ## Протокол приёмки (§24.5)

Каждый named fault закрывается одним из трёх: (а) существующий тест краснеет при целевой инъекции этой
поломки; (б) приложен падающий acceptance-тест на НЕИЗМЕНЁННОМ кандидате; (в) для класса **ВЗГЛЯД** —
записанное наблюдение итогового состояния с точной командой и её выводом. Процент не заменяет список.
Число без команды, которой оно получено, недействительно.
