# Global Admin UI Initiative

**Статус:** этап 1 в работе (CONNECT + заглушки).
**Рабочая ветка:** `wt/cabinet-ui-rebuild` (не `feat`).
**Taskdb:** карточка не заведена — bounded plan по запросу владельца 2026-08-19.

## Цель

Собрать кабинет глобального администратора как отдельную продуктовую поверхность: не кабинет врача,
клиенты — клиники и специалисты, аналитика — только агрегаты платформы.

Первый этап — страница аналитики. Остальные экраны кабинета (`/app/admin/*`, Аккаунт) живут в этой
папке по мере указаний владельца, не разъезжаются по чужим инициативам.

## Границы

- Не клиническая аналитика врача (вкладки «Клиенты / Приложение / Контент / Сопровождение» врача сюда
  не переносятся).
- Нет drill-down до конкретного пациента.
- К базе — только drizzle-порты webapp ([AGENTS.md](../../../AGENTS.md) §5). Новый сырой SQL не писать.
- Живой URL пока `/app/doctor/analytics` под `(global-admin)`; смена пути — отдельное owner-указание.
