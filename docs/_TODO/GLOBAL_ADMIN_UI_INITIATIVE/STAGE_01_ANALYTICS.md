# Этап 1 — страница аналитики глобального админа

**Статус:** реализация CONNECT+заглушек на `/app/doctor/analytics`.
**Маршрут:** `/app/doctor/analytics` (layout `(global-admin)`). Сейчас заглушка «Аналитика пока недоступна.»
**UI:** один экран, блоки друг под другом. Вкладки врача не использовать (`DoctorAnalyticsShell` /
`doctorAnalyticsTabs` — клиническая оболочка, сюда не подключать).
**Период:** один контрол на всю страницу. Переиспользовать `AnalyticsPeriodToolbar` (сутки / неделя /
месяц / свой), не второй пикер.

Owner-текст без смягчения: [`OWNER_DECISIONS.md`](OWNER_DECISIONS.md).

## Как читать статусы механик

| Статус | Значение на этом этапе |
| --- | --- |
| **CONNECT** | Данные уже пишутся. На этапе 1 показать живые цифры (новый platform-агрегатор, без drill-down). |
| **STUB** | Блок на экране есть, цифра «—» / «скоро». Оценка — что дописать, чтобы стало CONNECT. |
| **NEW** | Продуктовая механика ещё не существует; аналитика завязана на неё. |

Оценки — рабочие дни одного исполнителя на webapp, без полного CI.

Сумма этапа 1 (страница CONNECT+STUB): **3–4 дня**.
Ссылка хостинга в упражнении **не входит** в этот кабинет — [`DOCTOR_UI_REWORK` UI-EX-HOST](../DOCTOR_UI_REWORK_2026-07-20/PLAN.md).
Пока её нет, счётчик iframe упражнений — заглушка.

## Запреты

- Не показывать регистрации и push.
- Не переносить вкладки «Контент» и «Сопровождение» врача.
- Не открывать карточки пациентов / клиник из цифр (агрегат only, ruling 2026-07-26).
- К базе только через порт модуля на drizzle. Новый модуль `platform-analytics` (не раздувать
  `product-analytics`: тот — ingest page_view, здесь — срезы нескольких доменов).

### 1. Клиенты платформы — CONNECT

Вместо клиентов врача: клиники / специалисты / пациенты.

| Цифра | Источник | Статус |
| --- | --- | --- |
| Сейчас: клиники | `be_organizations` | CONNECT |
| Сейчас: специалисты | memberships / specialists организации | CONNECT |
| Сейчас: пациенты всего | enrollments / `platform_users` role client — **без** карточки человека | CONNECT |
| График периода | по `created_at`: поток новых за день **и/или** восстановленный запас «сколько было на дату» | CONNECT |

График запаса восстанавливается как `count(*) WHERE created_at <= день` (удалённых мало; если появится
жёсткое удаление — оговорить). Не нужен snapshot-table на этапе 1.

- [ ] **GA-A-01** Три KPI «сейчас» + график по периоду (клиники, специалисты, пациенты).

Оценка: **0.5–0.75 дня**.

### 2. Заходы (вместо «Приложение») — CONNECT

Не регистрации, не push.

Есть ingest: `product_analytics_*` (`page_view`, `app_open`, `heartbeat`), hourly rollup,
`page_key`, `entry_channel` (pwa/telegram/max/browser). Кабинет пациента уже ключ
`/app/patient/cabinet`. Врачебные пути — по префиксу `/app/doctor` vs `/app/patient`.
Сайт vs приложение: `entry_channel` browser vs pwa (мессенджеры — отдельно в том же разрезе,
не прятать).

Нет готового **разреза роль врача / роль пациента** в hourly dim — на этапе 1 резать по `page_key`
префиксу кабинета. Это совпадает с «заходы врачей / заходы пациентов», не с «уникальные люди с двумя
ролями».

- [ ] **GA-A-02** Заходы на страницы и в кабинет: все врачи отдельно, все пациенты отдельно; топ
      страниц за период; без регистраций и push.

Оценка: **0.75–1 день** (переиспользовать агрегаты `buildAdminDashboard`, отрезать push/register).

### 7. Объём видео — CONNECT оригиналы/ступени, STUB конвертация

Ступени длительности (минуты): ≤3, 3–5, 5–7, 7–10, 10–15, 15–20. Ролик без
`video_duration_seconds` — отдельная корзина «длительность неизвестна», не смешивать со ≤3.

| Метрика | Источник | Статус |
| --- | --- | --- |
| Оригиналы, байты | `media_files.size_bytes` video | CONNECT |
| Среднее на видео | сумма / число | CONNECT |
| Ступени длительности | `video_duration_seconds` | CONNECT |
| Упражнения vs CMS | join: упражнение через `lfk_exercise_media` → uuid медиа; CMS — `content_pages.video_url` `/api/media/…` плюс вставки в body, **не** warmup | CONNECT с оговоркой: медиа в markdown без разбора body на этапе 1 можно не искать — только поле `video_url` и прямая привязка упражнения. Иначе STUB «вложенные в текст» |
| Объём HLS/конвертации | в БД суммы артефактов нет (`hls_artifact_prefix` без size) | **STUB** |

- [ ] **GA-A-07a** Оригиналы, среднее, ступени — отдельно упражнения и CMS.
- [ ] **GA-A-07b** Заглушка «объём конвертации» + оценка: писать суммарный размер HLS в `media_files`
      или считать по S3 prefix. Оценка до CONNECT: **1–2 дня** (схема + worker).

Оценка 07a: **0.75 дня**.

### 8. Активность пациентов

| Метрика | Источник | Статус |
| --- | --- | --- |
| Отметки выполнения | `program_action_log` `action_type = done` (+ при необходимости practice completions не-warmup) | CONNECT |
| Из них с повторениями/сложностью | `payload.reps` / difficulty в том же логе | CONNECT |
| Самочувствие на главной | `symptom_entries` по `general_wellbeing` / mood check-in | CONNECT |
| Выраженность симптома (дневник) | таблицы `symptom_trackings` / `symptom_entries` есть; пациентский дневник симптома **не сдан** (MVP дневника — самочувствие, вкладки симптомов выключены). Owner: **заглушка** | **STUB** |
| % активности по программе | дни месяца с `page_view` путей программы/упражнений vs дни с `done`, среди тех у кого есть активный instance; среднее по пациентам | CONNECT формулой; уточнить «месяц» = выбранный период, если период ≠ месяц |
| Просмотры видео: всего | `media_playback_resolution_events` | CONNECT |
| Уникальные | `media_playback_user_video_first_resolve` (lifetime first) — для **уникальных за период** нужен distinct user+media по events за окно | CONNECT по events, не путать с first-ever |
| По времени | hourly `media_playback_stats_hourly` | CONNECT как ряд за период. **Длительность просмотра сессии не пишется** — это не CONNECT |
| Выдача HLS / ошибки | hourly delivery hls vs mp4; `media_playback_client_events` (`hls_fatal`, `video_error`); proxy errors | CONNECT |
| Iframe хостинга, показанные пациентам | события показа iframe нет | **STUB** + NEW ingest при GA-V / CMS iframe mount |

- [ ] **GA-A-08a** Отметки, reps/сложность, самочувствие главной, просмотры файла (уник/всего/ряд/HLS/ошибки).
- [ ] **GA-A-08b** % активности по программе за выбранный период (знаменатель — пациенты с назначенной
      программой).
- [ ] **GA-A-08c** Заглушка «дневник выраженности симптома».
- [ ] **GA-A-08d** Заглушка «показы iframe хостинга пациентам». Оценка до CONNECT: **0.5 дня** (один

Оценка 08a+08b: **1–1.25 дня**. Заглушки 08c/08d: в пределах GA-A-00.
