# Owner decisions — Global Admin UI

Побеждает более поздняя дата. Смягчать формулировки нельзя.

## 2026-08-19 — аналитика платформы и видео

Источник: указание владельца в чате (план + схема кабинета).

1. На странице аналитики глобального админа **наверху выбор периода на всю страницу**.
2. Блок «клиенты» врача **удаляется**. Вместо него клиенты платформы: сколько **клиник**, **специалистов**,
   **пациентов (всего)**. Цифра **«сейчас»** и **график по выбранному периоду**.
3. Вкладку «приложение» врача **убрать**. Считать заходы на отдельные страницы и в кабинет (приложение/сайт)
   **по всем врачам и по всем пациентам отдельно**. Регистрации не показывать. Push не показывать.
4. «Контент» и «сопровождение» врача **убрать** — это к врачу.
5. Блок: сколько **записались / отменили** за период — по всем клиникам.
6. Сколько **назначено программ упражнений**, сколько **оформлено визитов с карточками**.
7. Сколько создано **материалов CMS** — статьи, **не разминки**.
8. Сколько **упражнений создано специалистами** всего и сколько **в среднем** (только по тем, кто что-то создал).
   Из них: с **видео пациента (персональным, с приёма)** и **общих с видео специалиста**. Из видео: **файлы** vs
   **YouTube / RuTube / VK Видео iframe**.
9. Объём видео: оригиналы (трафик), объём конвертации, среднее на видео, длительность ступенями
   `до 3 / 3–5 / 5–7 / 7–10 / 10–15 / 15–20` минут. **Отдельно упражнения и CMS**.
10. Файл упражнения: **максимум 10 минут**, иначе ссылка YouTube / RuTube / VK Video / Vimeo.
    Файл CMS: **максимум 20 минут**.
11. В упражнение **нужно** вставить ссылку на YouTube / RuTube / VK Видео / Vimeo — открывается в iframe.
    Кабинет специалиста, не глобальный админ: [`DOCTOR_UI_REWORK` UI-EX-HOST](../DOCTOR_UI_REWORK_2026-07-20/PLAN.md).
12. Активность пациентов: отметки выполнения; сколько из них с повторениями/сложностью; отметки самочувствия
    на главной; выраженность симптома (дневник симптома) — **заглушка, в продукте ещё нет**; средний %
    активности по программе (если назначена): дни в месяц с заходом на страницы упражнений vs ещё и отметка;
    просмотры видео (уникальные, всего, по времени, выдача и ошибки HLS); сколько показано пациентам
    YouTube / RuTube / VK Видео iframe.
13. Сейчас: **план**. Подключить то, что уже есть в данных; остальное — заглушки с оценкой.

## 2026-07-26 — глобальный админ не врач

Клиенты админа — клиники и специалисты, не пациенты. Платформенная аналитика — только агрегаты.
Не собирать клиническую аналитику врача под этим маршрутом.
