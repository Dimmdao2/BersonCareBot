# Очередь независимого аудита ночной волны 28.07

**Владелец, 28.07:** «тебе придётся запустить по очереди аудиторов по всем работам, которые ты не аудировал.
И аудиторов не поверхностных — на этом мы уже обжигались» + уточнение: «которые не аудировал **отдельный
агент**».

Уточнение важное: **проверка лидом собственным чтением аудитом НЕ считается.** Мина со счётчиком
SECURITY DEFINER под миграцией 0270 была поймана лидом (`b1899e8d2`) — это не отменяет необходимости
независимой проверки того же куска.

Правило гейта (канон бокса): аудитор проверяет **против плана владельца**, а не против отчёта исполнителя;
находка без соответствующего пункта плана — **вопрос владельцу, а не задача**. Отчёт исполнителя и зелёные
тесты сами по себе доказательством не являются.

## Почему слой 1 первый

Воркер умер на системной ошибке посреди работы. Лид закоммитил его 504 строки дословно, чтобы не потерять,
с пометкой «unverified, do not merge as is» — **и ветка унесла их дальше, а деплой выкатил на TEST**.
Затронуты: отправка сообщений интегратора, журнал сообщений, принципал организации, публичный вход по
почтовому коду, скрипт деплоя и конфиг рантайма интегратора. Ни один отдельный агент это не читал.

## Что аудитор обязан вернуть

Вердикт одной строкой (PASS / SHIP-WITH-FIXES / FAIL); построчная матрица по галочкам плана
«пункт → доказательство в коде → доказательство в рантайме → вердикт»; находки от тяжёлых к лёгким с
конкретным входом, который ломает; отдельная секция про мины деплоя («проверено, нет» либо список);
отдельная секция «ВОПРОСЫ ВЛАДЕЛЬЦУ» — туда уходит всё, чего нет в плане.
