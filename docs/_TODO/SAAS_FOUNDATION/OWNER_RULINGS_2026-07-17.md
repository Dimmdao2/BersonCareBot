## 1. Публичная ссылка записи клиники — ПОДТВЕРЖДЁН канон `/book/{publicSlug}` (#805)

Владелец выбрал вариант: **«/book/имя-клиники»** (из трёх предложенных: slug-путь / поддомен / только инвайты).

**Значит:** у каждой клиники публичный адрес вида `/book/<slug>`; сервер по слагу резолвит организацию
**до** чтений каталога. Общий `/book` без контекста клиники остаётся fail-closed. Поддомены — только
как будущие алиасы, DNS/nginx сейчас не трогаем. Персональные инвайт-токены — отдельный flow (#806),
не смешивать. Карточка #805 разблокирована в todo.
