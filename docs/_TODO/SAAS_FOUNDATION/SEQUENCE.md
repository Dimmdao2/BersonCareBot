# Последовательность работ — единственный источник порядка

> Зафиксировано 2026-07-15 по прямому указанию владельца. Этот файл отвечает на один вопрос: **что делаем
> следующим и почему**. Порядок меняется только владельцем. Агент, который хочет отклониться, — сначала
> спрашивает.
>
> Канонический план исполнения — `SAAS_ENFORCE_ROADMAP.md`. Этот файл — порядок над ним.

## Куда мы идём (слова владельца, 2026-07-15)

Всё доводится до боевого состояния **на ТЕСТОВОМ сервере**: сколько угодно организаций, тестовые клиенты, все
роли, админы, настройки. Там же дорабатывается интерфейс и маршруты — главный лендинг, вход для специалистов,
вход для клиентов. **Только после этого** система переносится на прод **копией**: копируется папка, проект
переименовывается с `bersoncare` на `therapysto`/`therapio`, поднимается на **новом домене**. К этому моменту
нужны интерфейс, оплата, магазин с пакетами упражнений и тарифная сетка — это то, что показывают инвесторам.

**Старый прод `bersoncare` — легаси, заморожен. Переключения прода не будет. Никогда.** Новый деплой рождается
со включёнными стенами. «На живом» = на тесте.

### Этап 5 — корень настроек · ЖДЁТ РЕШЕНИЯ ВЛАДЕЛЬЦА

**Не заплатка.** `system_settings` смешивает секреты (ключи интеграций, OAuth, VAPID) и настройки, которые
определяют интерфейс клиента. Стена повешена на таблицу целиком, поэтому пациентской роли закрыто и то, что
приложение **обязано** читать. Слова владельца: «ПРИЛОЖЕНИЕ ДОЛЖНО ЧИТАТЬ НАСТРОЙКИ, КАК ИНАЧЕ ВООБЩЕ????»

Флажков будут десятки, и это **не только** права из тарифа — это любые настройки, меняющие интерфейс клиента.
Аксессор с белым списком на каждый флаг — тупик, эту заплатку уже выкинули (коммит откатил роут
discussion-summary).

- [ ] 5.1 Разделить: секреты отдельно, настройки клиента отдельно; дать приложению читать вторые нормально.
- [ ] 5.2 Пока не сделано — роут `patient.program.item.discussion-summary` падает под стенами. Симптом
      оставлен видимым намеренно.

## Правило провенанса

Атрибуция «владелец решил X» **без ссылки на то, где он это сказал** — догадка агента, а не решение владельца,
и должна быть подписана как догадка. Этот репозиторий уже дважды дорого заплатил за нарушение этого правила.
