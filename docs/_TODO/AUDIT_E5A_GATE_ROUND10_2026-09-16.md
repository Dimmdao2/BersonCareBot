## MUST FIX-1 — тернарный контейнер обрывает путь деструктуризации

Строка оракула: клинические данные до завершения общего прохода не показываются.

`variableValueTargetsOf()` (`:237-256`) сначала разрешает инициализатор, затем
последовательно применяет путь деструктуризации. Но `valueTargetsOf()` (`:259-289`)
не раскладывает `ConditionalExpression`: тернарник возвращается одним непрозрачным
target. Следующий `memberValuesOf()` не видит в нём ни объектный, ни массивный
литерал, ставит только `unresolvedPotential`, а ранний read-check это состояние не
превращает в finding. Отдельный `resolveToFunctionBodies()` умеет тернарник
(`:414-419`), но до его ветвей после деструктуризации управление уже не доходит.

Две собственные обычные формы получили пустой `findings`, хотя вызывают
клиническое чтение до двери:

```ts
const source = request.method === 'GET'
  ? { fetchPatient: async () => buildAppDeps().treatmentProgram.getForPatient({}) }
  : { fetchPatient: async () => buildAppDeps().treatmentProgram.getCurrentForPatient({}) };
const { fetchPatient } = source;
const result = await fetchPatient();
// дверь стоит ниже
```

```ts
const source = request.method === 'GET'
  ? [async () => buildAppDeps().materialRating.listForPatient({})]
  : [async () => buildAppDeps().materialRating.getForPatient({})];
const [fetchRatings] = source;
const result = await Promise.all([fetchRatings()]);
// дверь стоит ниже
```

Это один корневой дефект, а не две находки. В обоих случаях все значения находятся
в локальных объявлениях и объектных/массивных литералах того же route-файла; нет
импорта обработчика, межмодульной фабрики или spread. Тернарник, литералы и
деструктуризация по отдельности уже объявлены поддерживаемыми и действительно
разрешаются. Поэтому шапка (`:14-18`), которая относит молчание к межмодульным
значениям, spread и отсутствию общего анализа потока, эту локальную композицию не
описывает.

Impact: разработчик обычным локальным выбором источника и последующей
деструктуризацией запускает чтение клинических данных до общей двери, а обязательный
lint-гейт остаётся зелёным. Парная мутация каждой формы — перенос двери выше вызова —
дала ноль findings, то есть образцы краснеют/зеленеют именно по проверяемому порядку.
