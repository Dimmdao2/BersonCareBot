## Правила ведения, которые уже стоили нам времени

- **Ход не заканчивается ожиданием.** Ни ожиданием CI, ни ожиданием воркера, ни будильником. Ход
  заканчивается либо запущенной работой, либо названным блокером. 22.08 сессия простояла семь часов
  ровно потому, что ход завершился ожиданием, а таймер не сработал.
- **Три ветки параллельно, четвёртый слот свободен** под коррекции и приёмку.
- **`--execute` на DEV — только у одной назначенной ветки за раз**, иначе они сводят базу под себя
  по очереди и затирают друг друга.
- **Приёмка — своей проверкой против реальности**, не по отчёту воркера. Отчёт «зелено» доказательством
  не является.
