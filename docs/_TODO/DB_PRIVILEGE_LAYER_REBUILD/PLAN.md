Основания: `FACTS.md`. **Каждый шаг ниже ссылается на параграф фактов или на коммит.** Строка без
ссылки в этот план не попадает — так v4 набрал 247 строк прозы и был отброшен (`FACTS.md` §9.8).

**Статус:** шаг 0 не закрыт → шаги 1+ не начинать.
**Деплой на TEST остановлен решением владельца.** План ничего не выкатывает.

## Правило приёмки — одно, для каждого шага без исключений

Инкремент принимается, только если в сообщении коммита лежат **три транскрипта** (`FACTS.md` §7):

1. **КРАСНЫЙ** — гейт падает на сегодняшней непочиненной реальности;
2. **ЗЕЛЁНЫЙ** — гейт проходит после починки;
3. **СНОВА КРАСНЫЙ** — гейт падает при повторном внесении дефекта в откатываемой транзакции.

Нет (1) — гейт прошёл бы и так. Нет (3) — гейт не подключён к тому, что заявляет.
**«Аудит доволен» приёмкой не является** — приёмка это транскрипты + галочка здесь + живой прогон.

**Роли на каждом шаге, три разных агента, не один и не одна модель:**
доказыватель (правит только гейт и одну миграцию, прозу писать не имеет права) ·
ломатель (Opus, не видит рассуждений доказывателя; его задача — провести дефект мимо зелёного гейта;
успех ломателя = шаг отклонён) · я (сверяю с этим файлом).

**Стоп-правило:** два круга подряд без закрытой галочки здесь → эскалация (сильнее модель И
аудитору, И фиксеру, шире контекст); ещё два таких — стоп и вопрос владельцу.

## Растяжка, которую читает владелец — одна команда в неделю

```bash
git log --since="7 days ago" --grep="db-privileges" --numstat --format="" \
 | awk '{a=$1+0; if($3 ~ /\.md$/) d+=a; else c+=a} END {print ".md:", d+0, " executable:", c+0}'
```
