# Слой прав БД — где что лежит

Три документа. Всё остальное — архив первоисточников.

| Файл | Что это | Когда читать |
|---|---|---|
| **[FACTS.md](FACTS.md)** | что установлено. Каждое утверждение помечено источником | всегда первым |
| **[PLAN.md](PLAN.md)** | что делаем. Каждая строка ссылается на факт или коммит | перед любой работой |
| `evidence/` | первоисточники и черновики. **Содержит опровергнутое** | только чтобы поднять, откуда взялось утверждение |

---

## Метки источника — почему они есть

Дневная путаница выросла из того, что проверенный факт, отчёт агента и догадка выглядели в тексте
одинаково, и решения принимались по всем трём как по равным.

`[ФАКТ]` выполненная команда · `[КОД]` прочитанный исходник `файл:строка` ·
`[СТЕНД]` доказано прогоном красный→зелёный→снова красный · `[ОТЧЁТ]` сказал агент, не перепроверял ·
`[ИССЛЕД]` внешняя практика — факт о мире, не о нас · `[ГИПОТЕЗА]` не проверено ничем ·
`[ОПРОВЕРГНУТО]` снято, указано чем.

Подробно — `FACTS.md` §0. **Метка без указания, чем проверено, меткой не считается.**
