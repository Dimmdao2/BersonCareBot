# Горизонт доступной онлайн-записи по клинике

## Решение владельца — 04.09.2026

- [ ] `BAH-01` Убрать жёстко заданный горизонт в 14 дней из публичной записи: доступные дни и слоты ограничиваются настройкой клиники «на сколько дней вперёд показывать календарь записи».
- [ ] `BAH-02` Настройка относится к клинике и доступна в настройках записи специалиста; она не является глобальной константой или индивидуальным свойством пациента.
- [ ] `BAH-03` При создании новой клиники в базе создаётся значение по умолчанию — 30 дней (один месяц).
- [ ] `BAH-04` Добавить целевые проверки: дефолт для новой клиники и применение клинического горизонта в выдаче доступных дней/слотов.

## Граница

Не возвращать старую локальную правку из `main` и не вливать её отдельным коммитом: она была временным обходом. Реализация должна использовать одно клиническое значение, а не новый hardcode.
