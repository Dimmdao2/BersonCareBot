# Медицинский и оздоровительный режим терминологии

Статус: очередь после текущего системного пакета Track D.

## Решение владельца 02.09.2026

Текущая настройка одного слова «клиент / пациент» должна стать единым режимом приложения:

- медицинский режим использует медицинскую терминологию;
- оздоровительный режим заменяет медицинские слова и фразы согласованными немедицинскими аналогами во всём пользовательском интерфейсе;
- переключение должно действовать системно, а не как набор независимых настроек отдельных полей;
- до реализации нужен полный инвентарь видимых терминов и предложение пар формулировок для обоих режимов.

Примеры направления, данные владельцем: «диагноз» → «результат диагностики» или «предположение»; «клинические тесты» → «функциональные тесты». Окончательные пары определяются после исследования контекста каждой фразы.

## Этапы

- [ ] **MWT-01 — Инвентарь.** Найти все видимые пользователю медицинские термины и фразы во всех поверхностях приложения, включая тексты из БД/CMS, письма, уведомления, ботов, экспорт и печатные материалы; отделить доменные идентификаторы и юридически обязательные формулировки, которые нельзя механически переименовывать.
- [ ] **MWT-02 — Матрица терминов.** Для каждого найденного контекста предложить согласованную пару «медицинский режим / оздоровительный режим», без потери смысла и без механической замены частей слов.
- [ ] **MWT-03 — Единый механизм.** Спроектировать один источник режима и один типизированный слой терминологии для всех поверхностей, включая поведение по умолчанию и границы арендатора; не плодить настройки отдельных слов.
- [ ] **MWT-04 — Решение владельца.** Представить владельцу матрицу спорных терминов и варианты только там, где продукты имеют разный смысл; записать выбранные формулировки до реализации.
- [ ] **MWT-05 — Реализация.** После MWT-04 перевести интерфейс и каналы на единый механизм, убрать старую одиночную настройку без параллельного обходного пути.
- [ ] **MWT-06 — Приёмка.** Проверить обе конфигурации на настоящих ролях и каналах; смена режима должна менять весь согласованный словарь и не менять медицинские данные, права или бизнес-поведение.

## Граница текущего запуска

Первый агент выполняет только MWT-01–MWT-03 и готовит MWT-04. Код продукта до решения владельца по матрице не меняется.
