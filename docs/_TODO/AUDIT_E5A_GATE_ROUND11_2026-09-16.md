## MUST FIX-1 — initializer значения по умолчанию в деструктуризации не входит в разрешение

Строка оракула: клинические данные до завершения общего прохода не показываются.

Тернарник в `valueTargetsOf()` теперь раскладывается корректно, но следующий шаг
теряет initializer `BindingElement`. `bindingMatchInName()` сохраняет только путь
`pull`, а `variableValueTargetsOf()` применяет этот путь только к initializer всего
объявления. В форме ниже пустая ветвь тернарника должна передать управление
локальному `fallback`, однако его тело не становится target:

```ts
const fallback = async () =>
  buildAppDeps().treatmentProgram.getForPatient({});
const source = request.method === 'GET'
  ? {}
  : { pull: async () => ({}) };
const { pull = fallback } = source;
const result = await pull();
// общая дверь стоит ниже
```

Публичная `checkSource()` вернула `[]`. Зеркальная безопасная мутация — перенос
двери выше `await pull()` — также вернула `[]`, поэтому молчание относится именно
к потерянному default-target, а не к посторонней причине.

Та же форма показывает расхождение двух половин разрешателя. Если оба локальных
кандидата обработчика проходят дверь, но один приходит через default:

```ts
const fallback = async () => {
  // общая дверь
  return Response.json({ ok: true });
};
const source = process.env.NODE_ENV === 'test'
  ? {}
  : { pull: async () => {
      // общая дверь
      return Response.json({ ok: true });
    } };
const { pull = fallback } = source;
export const GET = pull;
```

`checkSource()` возвращает ровно один ложный finding `exported GET must fail
closed`: handler-путь переносит `unresolvedPotential` в fail-closed verdict, а
ранний read-путь тот же неразрешённый target молча игнорирует. Следовательно,
обе половины не понимают default initializer одинаково: безопасный handler
краснеет, а небезопасное раннее чтение зеленеет.

Это не заявленная граница шапки (`:14-16`): все значения и функции объявлены
локально в одном route-файле, здесь нет import handler, межмодульной фабрики или
spread. Default при деструктуризации опционального локального registry/source —
обычная форма рефакторинга; её можно написать случайно, не пытаясь обойти гейт.

Impact: обычный локальный refactor способен открыть чтение клинических данных до
обязательной двери при зелёном гейте; зеркальная законная форма экспортированного
handler способна остановить разработку ложным красным. Это один корневой дефект —
default initializer отсутствует в локальном разрешении.
