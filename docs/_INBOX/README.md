# 📥 INBOX — исторические входящие

Эта папка хранит прежние owner-drafts и не является очередью исполнения. Текущее состояние tracked workstream
читается через taskdb, а правила постановки и выбора работы находятся только в `AGENTS.md` §1 и §24.

Новый файл здесь создаётся только по прямой просьбе владельца сохранить сырой input именно в `_INBOX`; сам файл
не запускает работу и не требует автоматически создавать initiative, plan или taskdb-карточку.
